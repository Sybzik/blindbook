# Security and privacy reports

Blindbook's core claim is that nobody, including its operator, can link a bet to a person or a payout to a bet.
If you find anything that breaks that claim, a leak, a linkability attack, a way to forge slips or drain the reserve, please tell us.

- Check [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md) first: if your finding isn't listed there, it's new.
- Report privately through GitHub's **"Report a vulnerability"** (Security tab) on this repository.
- Please don't open public issues for unfixed leaks.

This is hackathon software running with small stakes. Don't put in more than you can afford to lose.
